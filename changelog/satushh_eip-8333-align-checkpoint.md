### Added

- Implement EIP-8333, anchoring FFG checkpoints to the epoch boundary block behind the new `HEZE_FORK_EPOCH` config parameter (defaults to far-future). Adds `slots.CheckpointSlot` and `helpers.CheckpointRoot`, resolves attestation target matching, justified checkpoint recording, fork choice targets, checkpoint viability, finalization pruning, and the weak subjectivity window through the checkpoint slot, computes justified balances at the checkpoint epoch, moves the finalized-slot gossip bounds for blocks, blob sidecars, data column sidecars, payload envelopes, and peer status validation to the checkpoint slot, resolves the `finalized`/`justified` state ids through the checkpoint slot so checkpoint sync origins descend from the checkpoint root, and derives the checkpoint sync origin epoch from the state slot instead of the boundary block slot. The minimal e2e now schedules `HezeForkEpoch` at epoch 2 to cover the activation live. A design doc is included at `docs/eip-8333-design.md`.
